Project Description
This project demonstrates the use of JSON, modern JavaScript, the fetch() API, and jQuery for client-side web development.

Project Files

1.books.json
Contains a JSON dataset with two book objects. Each book includes its title, author, publication year, and genres.

2.books.html
Uses the JavaScript fetch() API to retrieve and display information from books.json.

3.jquery-dom.html
Demonstrates three jQuery operations:

* .text() - Changes the text of an HTML element.
* .addClass() - Adds a CSS class to an HTML element.
* .on("click",...)-Handles button click events.

How to Run the Project

1.Download or clone this repository.
2.Open the project folder using Visual Studio Code.
3.Install the Live Server extension.
4.Right-click books.html and select Open with Live Server.
5.To test jQuery, open jquery-dom.html using Live Server. 
6.Ensure you have an internet connection to load the jQuery CDN.
